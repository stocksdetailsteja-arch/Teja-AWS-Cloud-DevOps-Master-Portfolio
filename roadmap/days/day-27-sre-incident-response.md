# Day 27: SRE & Incident Response

## Mission
Conduct a controlled outage and post-incident review.

## Core topics
SLOs, error budgets, runbooks and incident command.

## Execution checklist
- [ ] Capture environment and version baseline
- [ ] Explain architecture and normal flow
- [ ] Complete guided implementation
- [ ] Run positive and negative validation
- [ ] Introduce one controlled failure
- [ ] Record symptoms, evidence and investigation
- [ ] Verify root cause and smallest safe fix
- [ ] Exercise rollback or recovery
- [ ] Review security and least privilege
- [ ] Inventory cost and remove unnecessary resources
- [ ] Answer ten interview questions aloud
- [ ] Update screenshots, documentation and Git evidence
