# 🔥 SRE, Incident, DR & FinOps: Troubleshooting Scenarios

## Scenario 1: Component unavailable
Document symptoms, recent changes, status, logs/events, dependencies, verified root cause, fix, rollback and prevention.

## Scenario 2: Permission denied
Trace the acting identity, credential source, effective policy or RBAC decision, denied action, target resource and explicit deny conditions.

## Scenario 3: Configuration drift
Compare desired state, deployed state and runtime state. Identify the source of mutation and restore through the authorized workflow.

## Scenario 4: Performance degradation
Establish baseline, scope, saturation, latency, errors, dependency behavior and capacity. Avoid treating CPU as the only signal.

## Scenario 5: Recovery
Restore a known-good version, validate data and dependencies, run regression tests and preserve the incident timeline.
